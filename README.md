# Integral Dental - Protótipo de Landing Pages

Este projeto contém 3 variações de landing pages para a **Integral Dental**, desenvolvidas com React, Vite, Tailwind CSS, shadcn/ui e Framer Motion.

## 🎯 Sobre o Projeto

A Integral Dental atua desde 1994, criada e administrada por dentistas. Este protótipo apresenta três variações de páginas seguindo a identidade visual e objetivos da marca:

### Variação 1 - Geral
Landing page moderna e completa apresentando todos os serviços:
- Plano Empresarial
- Plano Familiar  
- Plano Especial de Ortodontia
- Depoimentos de clientes
- Benefícios e diferenciais

### Variação 2 - Empresarial
Foco em empresas e RH com:
- Soluções corporativas
- Números e resultados
- Portal exclusivo para RH
- Formulário de captação de leads empresariais

### Variação 3 - Família & Ortodontia
Foco em famílias com destaque para:
- Planos por faixa etária (crianças, adolescentes, adultos, idosos)
- Plano especial de ortodontia em destaque
- Cuidado integral em todas as fases da vida

## 📦 Instalação

```bash
# Clone o repositório
git clone <url-do-repositorio>

# Entre na pasta do projeto
cd integral-dental-prototipo

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## 🎮 Navegação

O protótipo possui um sistema de navegação fixo na parte inferior que permite:
- Navegar entre as 3 variações de páginas
- Visualizar qual página está ativa
- Ver o nome descritivo de cada variação

Use os botões de seta ou clique nos indicadores de página para navegar.
